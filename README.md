# 🎬 Sistema de Cadastro de Filmes

## 📌 Sobre o Projeto

O **Sistema de Cadastro de Filmes** é um projeto desenvolvido em Java com o objetivo de praticar conceitos básicos de programação e lógica computacional.

O programa permite cadastrar, listar, pesquisar, atualizar e remover filmes por meio de uma interface de janelas utilizando a biblioteca `JOptionPane`.

## ⚙️ Funcionalidades

O sistema possui as seguintes funcionalidades:

- **Cadastrar filme:** permite adicionar um novo filme ao sistema.
- **Listar filmes:** exibe todos os filmes cadastrados.
- **Pesquisar filme:** procura um filme pelo título.
- **Atualizar filme:** permite modificar as informações de um filme.
- **Remover filme:** exclui um filme cadastrado.
- **Sair:** encerra o programa.

## 🎞️ Informações dos Filmes

Cada filme possui quatro informações:

- Título;
- Diretor;
- Ano de lançamento;
- Gênero.

## 💻 Tecnologias Utilizadas

- Java;
- Biblioteca Swing;
- JOptionPane;
- IDE de desenvolvimento Java (NetBeans, Eclipse ou IntelliJ IDEA).

## 📚 Conceitos de Programação Aplicados

Durante o desenvolvimento foram utilizados conceitos fundamentais de Java:

- Variáveis;
- Vetores (Arrays);
- Estruturas condicionais (`if/else`);
- Estrutura de seleção (`switch/case`);
- Estruturas de repetição (`while` e `for`);
- Métodos;
- CRUD (Create, Read, Update e Delete);
- Tratamento de exceções (`try/catch`).

## ▶️ Como Executar o Projeto

1. Abra sua IDE de desenvolvimento Java.
2. Crie ou abra um projeto Java.
3. Adicione o arquivo `Main.java`.
4. Copie o código-fonte do projeto.
5. Execute a classe `Main`.
6. Utilize o menu apresentado para gerenciar os filmes.

## ⚠️ Observação

Os dados são armazenados temporariamente em vetores na memória do programa. Portanto, ao encerrar a aplicação, os filmes cadastrados são perdidos.

## 🎯 Objetivo Acadêmico

Este projeto foi desenvolvido com finalidade educacional, buscando colocar em prática os conhecimentos adquiridos durante os estudos de programação em Java, principalmente estruturas de controle, vetores, métodos e operações CRUD.
